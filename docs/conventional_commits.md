Se utiliza **Conventional Commits** en inglés, con el formato:

```
tipo(scope): descripcion
```

**Ejemplos:**

```text
feat(auth): add jwt login endpoint
fix(styles): correct input field alignment
docs(readme): update project overview
```

| Tipo | Uso |
|------|-----|
| `feat` | Nueva funcionalidad |
| `fix` | Corrección de un bug |
| `docs` | Documentación |
| `style` | Formato, sin cambios semánticos |
| `refactor` | Reestructuración de código |
| `test` | Agregado o corrección de tests |
| `chore` | Tareas de mantenimiento |
