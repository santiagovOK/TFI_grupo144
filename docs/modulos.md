# Listado de Módulos del Sistema

El proyecto **Gym Manager** se divide en los siguientes módulos estructurales:

## Módulos de Backend (Spring Boot)
1. **Módulo Auth**: Seguridad y validación JWT.
2. **Módulo User**: Gestión de perfiles (Admin, Staff, Socio).
3. **Módulo Enrollment**: Asignación de pases y control de vigencia.
4. **Módulo Payment**: Registro de cobros.
5. **Módulo Access**: Motor de validación de entradas en puerta.

## Módulos de Frontend Panel Administrativo
1. **Dashboard**: Resumen métrico global.
2. **ABM**: Interfaces CRUD para Usuarios, Inscripciones y Pagos.

## Módulos de Frontend Terminal
1. **Validación Visual**: Interfaz para ingreso de DNI y feedback de acceso.
